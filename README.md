# Real-Time Stock Market Dashboard

## Project Overview

The Real-Time Stock Market Dashboard is a Python-based web application developed during my Python Developer Internship. The application allows users to monitor stock market information through an interactive dashboard.

Users can select a company and time period to view current stock information, historical price trends, trading volume, and basic company details.

## Objectives

- To develop an interactive stock market dashboard.
- To retrieve stock market data programmatically.
- To display current stock price information.
- To visualize historical stock price trends.
- To display trading volume and recent market data.
- To provide a simple and user-friendly interface.

## Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- yfinance

## Main Features

- Stock selection
- Current stock price
- Price change percentage
- Day high and day low
- Historical price visualization
- Trading volume visualization
- Recent market data table
- Company information
- Interactive dashboard
